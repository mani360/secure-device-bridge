# Contributing

Keep changes small, document behavior, and run the build, lint, and JVM tests listed in the README. Explain the scenario and validation in each pull request.

Use only original or appropriately licensed public code. Do not contribute employer/customer code, commercial SDK binaries, credentials, private certificates, device dumps, or biometric data. Use synthetic fixtures. New device adapters need documented licensing and threading/cancellation contracts.

Reserved directories describe future boundaries; avoid adding empty Gradle modules without an implementation need.
